TTEXTO DE APOIO01

Modelagem relacional em poucas etapas

Um roteiro rápido para sair de uma situação do cotidiano e chegar a tabelas com relações claras.

Ler resumo ＋
  1. Identifique as entidades do problema e dê nomes no singular.
  2. Liste atributos e escolha um identificador para cada entidade.
  3. Defina os relacionamentos e suas cardinalidades.
  4. Mapeie o modelo para tabelas e marque chaves primárias e estrangeiras.
  5. Revise domínios, restrições e integridade referencial.

Exemplo: em uma biblioteca, Leitor, Livro e Empréstimo ajudam a representar quem retirou qual livro e quando.

{ }ROTEIRO PRÁTICO02

Do enunciado ao algoritmo

Uma sequência de perguntas para organizar o raciocínio antes de começar a programar.

Ler roteiro ＋
  1. O que o problema pede como resultado?
  2. Quais dados entram e quais condições precisam ser consideradas?
  3. Quais passos resolvem uma versão pequena do problema?
  4. Há decisões, repetições, vetores ou funções que simplificam a solução?
  5. Teste com exemplos, valores-limite e casos inesperados.

Depois, represente a solução em pseudocódigo e traduza-a para Java.

CPUMAPA DE CONCEITOS03

Um caminho pelos componentes do computador

Relacione processador, memória e entrada/saída para entender o percurso de uma instrução.

Ver conceitos ＋
  • Registradores: armazenam dados de uso imediato pela CPU.
  • Unidade de Controle: coordena a execução das instruções.
  • ULA: realiza operações aritméticas e lógicas.
  • Cache e RAM: mantêm dados disponíveis em diferentes níveis de acesso.
  • Barramentos: transportam dados, endereços e sinais de controle.

Use o diagrama da disciplina para conectar cada conceito a exemplos de hardware.

QMATERIAL AUTORAL · NÃO OFICIAL04

Simulado rápido: conceitos fundamentais

Questões para revisar relações, algoritmos, arquitetura e desenvolvimento web.

Abrir questões e respostas ＋
1. Em um modelo relacional, para que serve uma chave estrangeira?

Para representar uma referência a uma chave de outra tabela e apoiar a integridade entre registros.

2. Qual estrutura repete um bloco de instruções enquanto uma condição for verdadeira?

Uma estrutura de repetição, como while ou for, conforme a lógica do problema.

3. O que a memória cache busca melhorar?

O tempo de acesso a dados e instruções usados com frequência pelo processador.

4. Qual é o papel do HTML em uma página web?

Estruturar e dar significado ao conteúdo; CSS cuida da apresentação visual.
